Axmed iyo Riyadiisa

Ujeeddadu waa in la muujiyo sida qofku ugu guuleysan karo nolosha isagoo leh dadaal, dulqaad iyo yool cad

Axmed wuxuu ahaa wiil dhalinyaro ah oo jeclaa barashada technology-ga Inkastoo uusan haysan qalab badan, haddana maalin kasta wuxuu waqti u hurayay inuu barto HTML, CSS iyo JavaScript. Bilihii ugu horreeyay wuxuu la kulmay qaladaad badan laakiin ma uusan quusan Ugu dambeyn, wuxuu sameeyay website-kii ugu horreeyay taas oo siisay kalsooni uu ku sii wato riyadiisa.
