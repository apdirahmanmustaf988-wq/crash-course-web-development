# Role Mapping

## Website Example: YouTube

### Front-End (What Users See and Interact With)

-   Homepage layout
-   Video player interface
-   Search bar
-   Navigation menu
-   Like, Comment, and Share buttons
-   Channel pages
-   Responsive design for mobile and desktop

### Back-End (What Happens Behind the Scenes)

-   User authentication (login and sign up)
-   Storing videos and user data
-   Video recommendations
-   Processing video uploads
-   Database management
-   Handling comments, likes, and subscriptions
-   Streaming videos to users

# Tech Stack Research

## Front-End Framework: React

**What it is:** React is a popular JavaScript library used to build fast
and interactive user interfaces (UI).

**What it is used for:** - Building single-page applications (SPAs) -
Creating reusable UI components - Updating web pages efficiently without
reloading - Developing responsive and interactive websites

------------------------------------------------------------------------

## Back-End Framework: Django

**What it is:** Django is a high-level Python web framework used to
build secure and scalable web applications.

**What it is used for:** - Managing databases - Handling user
authentication - Processing business logic - Creating APIs - Managing
server-side operations - Building complete web applications quickly
