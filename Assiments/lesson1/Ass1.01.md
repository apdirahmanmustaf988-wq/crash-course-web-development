# Internet Mapping Activity

```text
Your Computer
      │
      ▼
Home Router
      │
      ▼
Internet Service Provider (ISP)
      │
      ▼
Internet Backbone
      │
      ▼
Routers
      │
      ▼
Server (if needed for services such as email or chat)
      │
      ▼
Friend's ISP
      │
      ▼
Friend's Router
      │
      ▼
Friend's Computer
```

- Your Computer
- Home Router
- Internet Service Provider (ISP)
- Internet Backbone
- Routers
- Server

# Web Components Match

| Component | Description |
|----------|-------------|
| **HTML** | The language used to create and structure web pages. |
| **URL** | The web address used to locate a webpage or resource on the Internet. |
| **HTTP** | The protocol used for communication between a web browser and a web server. |

## Correct Answers

- **HTML** → Creates and structures web pages.
- **URL** → The address of a webpage.
- **HTTP** → The communication protocol between a browser and a web server.
